# Buddy2api v2.2.2

发布日期：2026-10-17

小版本：WorkBuddy 出站按业务码处理失败，Key 可以选自动通道，小浣熊流式补上事件空行。

## WorkBuddy

- 发出去之前修工具历史，并把 `tool_choice` 收成字符串。`"none"` 仍保留 `tools`。
- DeepSeek 在思考已开或历史已有推理痕迹时，补缺的 `reasoning_content`。
- 渠道特征改写默认开着，无命中不动正文。`CB_GATEWAY_SANITIZE_FINGERPRINTS=off` 可关。
- 11115、11128、11101、11148、11155 直接回 400，不冷却、不换号。会话失效才标记过期。额度或短时限流只换号。
- 旧的 Codex 敏感词清洗已去掉。创建 Key 不再选智能体类型。已有 Codex 类型的 Key 可在 API Keys 页更新为普通 Key，字符串不变。

## 自动通道

- Key 可选「自动通道」，库里存 `*`。
- `通道/模型` 打到对应通道。`auto` 走第一个已有账号的通道。不带前缀的具体模型进第一家认得它且已有账号的通道。
- 额度用尽不会换到另一家。绑死一家的 Key 前缀对不上仍是 403。

## 账号域

- WorkBuddy 的 Key 可以限制账号域名：精确域名、`*.后缀` 或 `*`。
- 列表可以查看、修改和清空。刷新后域名变了不会把这个号交给被过滤的 Key。

## 小浣熊

- 流式事件之间补上空行。严格的 OpenAI 客户端不再把多行 JSON 读成一个事件。

## 管理页

- 切到日志或设置再回账号页，不再自动重读领取状态和官方额度。

## 升级说明

- 首次启动会给 `api_keys` 增加 `account_domain_filter` 列。
- 必须重启进程。
- Docker 用户需要重新构建镜像并重启服务。
