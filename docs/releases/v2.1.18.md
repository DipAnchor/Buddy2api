# Buddy2api v2.1.18

发布日期：2026-10-14

小版本：WorkBuddy 可以在管理页用浏览器登录加号。一键保活会先续期登录态，再领取今日积分。定时保活和定时领取放到设置页，默认关闭。

## 浏览器登录

- 账号页新增「浏览器登录」。国内站走 `codebuddy.cn`，国际站走 `workbuddy.ai`。
- 在官方页面登录后按 uid 入库。同一个号再次登录只更新凭证，权重和优先级保留。
- 凭证写入本机加密库。页面不显示 token。
- Docker 扫不到本机登录目录时，也可以用这个方式添加 WorkBuddy。

## 一键保活

- 「一键保活」先续期，再领取今日积分。「一键领取今日积分」只领取，并使用实心主题色。保活按钮用浅主题色，和白按钮分开。
- WorkBuddy、QClaw、千问办公、TraeWork 都能续期。每日领取只有 WorkBuddy 和 TraeWork；另外两家会显示「不支持领取」。
- 禁用账号跳过。网络抖动或上游临时失败不会把账号标成过期。连续 3 次确认登录失效后，才需要重新登录。
- 账号行在知道续期时间时显示剩余时间。

## 自动化

- 设置页第一张卡片是「自动化」，默认关闭。要打开开关并保存才会生效。
- 定时保活默认 22 点，定时领取默认 9 点。只在该小时的前 10 分钟执行一次。服务启动时不会自动跑。
- `CB_GATEWAY_KEEPALIVE=1` 或 `CB_GATEWAY_AUTO_CHECKIN=1` 可强制打开，设为 `0` 则强制关闭。不设时跟随设置页。

## 升级说明

- 无数据库迁移。
- 必须重启进程。旧进程没有保活接口，页面会显示保活失败。
- Docker 用户需要重新构建镜像并重启服务。
- 发版只改 `version.py`、README 和本说明；不改 `web/index.html` 里的版本字符串。
