# Buddy2api v2.2.7

发布日期：2026-10-23

小版本：WorkBuddy 出站改写 DeepSeek Harness 的固定身份句，避开渠道特征拒绝。

## WorkBuddy

- 只改固定句 `You are an AI agent powered by DeepSeek Harness.`，改成 `You are an AI agent powered by DeepSeek's Harness.`。
- 任务正文不改。只提到这个名字、但没有整句身份句时，也不改。
- 改写默认开着。`CB_GATEWAY_SANITIZE_FINGERPRINTS=off` 可关。
- `11128` 仍然直接回 400，不冷却、不换号。

## Docker

- 正式版发版成功后，同一个 workflow 会推送 `linux/amd64` 镜像到 `ghcr.io/wicm84266964/buddy2api:v2.2.7`，并移动 `latest`。
- 镜像 job 会忽略自身正在跑的检查，不再因此中断推送。

## 升级说明

- 必须重启进程。正在运行的旧进程不会改写这句。
- Docker 用户在镜像推送成功后，拉取 `v2.2.7` 再重启。源码部署继续 `docker compose up -d --build`。
