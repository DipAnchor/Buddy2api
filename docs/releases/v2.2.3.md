# Buddy2api v2.2.3

发布日期：2026-10-18

小版本：续期失败写明原因。TraeWork 把新令牌写回登录文件。管理页把保活改成续期。

## 千问办公

- 续期改用官方 1.3.1 客户端身份，不再附带访问令牌。
- 续期令牌失效时说明访问令牌还能用到何时，并提示重新登录后再导入。
- 本机登录文件里如果已有另一张续期令牌，会改用那张再试一次。

## TraeWork

- 续期成功后把新令牌写回 `storage.json`，避免下次导入盖回已作废的旧令牌。
- 第一次写回前留 `storage.json.buddy2api.bak`。
- 文件不在 TraeWork 登录目录，或账号对不上，不写回。写回失败不影响数据库里已经更新的令牌。
- 401 会提示打开 TraeWork 重新登录后再导入。

## Loomy

- 续期探测遇到连接中断会再试一次。
- 仍然失败时带上错误类型，例如 `ReadTimeout`。

## 管理页

- 「刷新登录」改为「续期」。成功提示是「续期成功」。
- 「一键保活」改为「一键续期并领取」。它仍然先续期，再领取今日积分。
- 设置里的定时开关只续期，标签改为「定时续期」和「续期时刻」。

## 升级说明

- 无数据库结构变更。
- 必须重启进程。旧进程不会把 TraeWork 新令牌写回文件，也不会重试 Loomy 探测。
- Docker 用户需要重新构建镜像并重启服务。
