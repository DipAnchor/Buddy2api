# Buddy2api v2.2.4

发布日期：2026-10-19

小版本：加上 Qoder，拆开 WorkBuddy 国际版，TraeWork 改为把工具交回本机。

## Qoder

- 新增中国版 `qoder` 和国际版 `qoder-i`。目录、登录文件和令牌不共用。
- 中国版本机导入 `auth.v1.dat`。国际版需要自己的登录文件和设备风控头。
- 支持模型列表、对话、活动领取和额度查询。
- 工具调用交回客户端。DeepSeek 要求的工具结果顺序、空正文和字符串参数会在发出前整理。

## WorkBuddy

- 国际版改为单独渠道 `workbuddy-i`，不再用域名筛子把国内外挤在一个池子里。
- 启动时把 `*.workbuddy.ai` 账号和只筛国际域名的 Key 迁到 `workbuddy-i`。Key 密文不变。
- 国际版的续期、额度和领取仍走原来的 WorkBuddy 接口，按账号域名选站点。

## TraeWork

- 对话从远程 `chat_sessions` 改为 `llm_utils_chat`。不再为每次对话新建并删除远程工作区。
- 工具调用交回本机智能体执行，可以读写本机文件。
- 发出前按这条接口整理消息：`content` 用内容块数组，助手工具字段用 `function_call`，工具参数用 JSON 字符串。

## 千问办公

- 编码器按 UTF-8 字节长度传递中文请求，避免完整智能体请求把 WASM 打崩。
- 编码失败后丢掉坏掉的运行时，后续请求可以重新加载。

## 网关

- `/v1/models` 不列出没有登录凭证的渠道。管理页仍可导入这些渠道。
- 黑金主题的错误框和失败提示改为深底浅字。
- 账号行菜单的续期不会把点击交到页面刷新上。

## 升级说明

- 首次启动会迁移 WorkBuddy 国际账号和只筛国际域名的 Key。
- 必须重启进程。旧进程仍会让 TraeWork 在远程工作区执行工具。
- Docker 用户需要重新构建镜像并重启服务。
- Ant Code 需要重新拉取模型列表，国际版在没有账号时才会从选择框消失。
