# Buddy2api v2.2.0

发布日期：2026-10-15

中版本：新增讯飞 Loomy 和商汤小浣熊两个通道。Loomy 长对话按预算裁剪。管理页账号操作收进常用按钮，用量切换不再跟着日期挪动。

## 新通道

- Loomy 和小浣熊默认启用。模型前缀分别是 `loomy/` 和 `xiaohuanxiong/`。
- 账号页可导入本机 `auth-session.json` 和 `auth.json`。一键保活、一键领取、一键读取供应模型都走到这两家。
- Loomy 没有独立的每日领取接口。领取会核对上游已经发放的每日余额。小浣熊领取会触发每日发放。
- 浏览器登录仍然只有 WorkBuddy。

## 长对话

- Loomy 发送前按 16 万 token 预算裁掉更早历史。设置页可改，`0` 只关闭发送前裁剪。
- 上游返回 11115、超大请求的 11133，或很长请求对应的 HTML 502 时，再裁一次并用同一个号重试。还是失败就回可读错误，不再转发 HTML 错误页。
- 其他通道发送前不裁。只有上游明确拒绝上下文时才补裁一次。
- 请求体上限默认 32 MiB，可用 `CB_GATEWAY_MAX_BODY_BYTES` 调整。

## 管理页

- 用量日期占固定宽度，今日、昨日、七天、30 天按钮不再跟着文字长短移动。
- 账号列表外面只留禁用、测试、删除。保存、额度、领取、刷新登录收进「⋯」，菜单浮在表格上面。
- 左上角标识改为 `wicm84266964`。

## 升级说明

- 无数据库迁移。
- 必须重启进程。旧进程没有这两个通道，也没有 Loomy 上下文裁剪。
- Docker 用户需要重新构建镜像并重启服务。Loomy 和小浣熊的本机登录文件请先在本机导入。
