# Buddy2api v2.2.1

发布日期：2026-10-16

小版本：QwenWork 每日赠分接入一键领取。QClaw 停止运营，通道下架，积分改走 WorkBuddy。Loomy 领取状态不再因读取抖动显示失败。

## QwenWork

- 一键领取和一键保活会领取千问办公每日赠分。
- 请求按 1.3.1 客户端：不带正文的 POST，并带 `X-QwenWork-App-Mode: standard`。
- 登录失效会先刷新再重试。失败信息带上游 `errorMessage`。

## QClaw

- 默认通道不再包含 QClaw。`CB_GATEWAY_PROVIDERS` 里的 `qclaw` 会忽略，不会阻止启动。
- 管理页不能再选 QClaw。一键读取供应模型不再扫它。
- 已绑定 QClaw 的 Key 返回 `QClaw is retired. Credits moved to WorkBuddy; switch this API key to workbuddy.`
- 已入库的 QClaw 账号和旧模型目录不会自动删除。

## Loomy

- 今天已经确认每日余额后，后续状态读取失败会保留「今日已领」，不再标成失败。

## 升级说明

- 无数据库迁移。
- 必须重启进程。旧进程仍会把 QClaw 当可用通道，也没有 QwenWork 赠分领取。
- Docker 用户需要重新构建镜像并重启服务。
