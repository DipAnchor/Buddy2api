# Buddy2api v2.2.6

发布日期：2026-10-23

小版本：保留自动续期和领取的失败记录；补上新装 Trae 的登录目录；正式版发版时推送 GHCR 镜像。

## 自动化日志

- 定时续期、定时领取、手动一键续期并领取、手动一键领取，都会按账号留下结果。
- 设置页新增「自动化日志」，默认只看失败。记录包含时间、来源、通道、账号和原因。
- 日志保留 30 天，最多 2000 条。登录凭据、请求头和长随机串会在入库前去掉。
- 一个账号领取或续期抛错时，其余账号继续处理。
- 请求日志页不变，仍然只记录对话请求。

## TraeWork

- 继续扫描 `%APPDATA%\TRAE SOLO CN\User\globalStorage`。
- 新装 Trae 同时扫描 `%APPDATA%\Trae CN\User\globalStorage`。
- 设置了 `CB_TRAEWORK_USER_DATA_DIR` 时只扫描指定目录。

## Docker

- 正式版发版成功后，同一个 workflow 会推送 `linux/amd64` 镜像到 `ghcr.io/wicm84266964/buddy2api:v2.2.6`，并移动 `latest`。
- 不发 Docker Hub，也不发 arm64。
- 第一次推送后，GitHub Packages 里的包可能是私有的。仓库所有者需要手动改成公开一次，匿名 `docker pull` 才可用。
- 已有版本标签默认不会被覆盖。

## 升级说明

- 启动时会自动创建 `automation_events` 表，不改现有账号和请求日志。
- 必须重启进程。正在运行的旧进程不会写入自动化日志，也不会扫描新的 Trae 目录。
- Docker 用户在镜像推送成功后，拉取 `v2.2.6` 再重启。源码部署继续 `docker compose up -d --build`。
