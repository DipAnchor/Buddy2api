# Buddy2api v2.2.5

发布日期：2026-10-21

小版本：千问办公不再打已下线的领取接口；非流式请求按 Key 绑定的通道转发。v2.2.4 之后已合入但未发版的改动都在这一版。

## 千问办公

- 每日赠分不再请求 `/api/v1/adapter/user/daily-credit-notice/claim`。这条地址认证后返回 404。
- 手动领取和定时领取改为读取钱包。当天到期的积分已到账时显示金额；还没到账时说明由千问办公按官方登录会话发放，不再算失败。
- 网关续期只换访问令牌，不能代替千问办公登录，也不能代领每日积分。
- 流式对话从转发的 SSE 里记录 prompt 和 completion tokens，不再把用量记成 0。

## 网关

- 非流式 `/v1/chat/completions` 会把 Key 绑定的通道传给调度。`workbuddy-i` 不再在非流式请求里落到国内账号池。
- 流式请求原来就是按绑定通道转发，这次没有改这条路径。

## 文档

- README 补上 Qoder 中国版和国际版的登录目录、模型名和通道列表。

## 升级说明

- 无数据库迁移。
- 必须重启进程。旧进程仍会请求已下线的领取地址，非流式请求也可能走错通道。
- Docker 用户需要重新构建镜像并重启服务。
